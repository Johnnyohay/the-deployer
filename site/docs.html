Sources

Every feed is read once a day. A search feed (Google News) covers sites that publish no feed of their own. The health column shows what each one returned on the last run.

SourceTierLast run

How it updates

  1. Every morning a GitHub Action reads the sources, keeps stories from the last few days, drops duplicates and noise, tags each one with its themes, type and the names it mentions, and writes the brief.
  2. Then the curator (a free AI: Groq, or a small open model when no key is set) rewrites the briefs of themes with new stories, picks dated upcoming events out of the news, adds names that keep coming up, and scores each theme's momentum.
  3. Finally the site and its data API are rebuilt and published. Nothing here costs money.

Change it

No code needed. Either:

  • Say it in plain words: open an issue in this site's GitHub repo titled Change my setup and describe what to add, drop or rename ("follow Mexico nearshoring too", "drop sports retail"). It is applied within a few minutes and the issue gets a summary of what changed.
  • Edit the files in topic/ on GitHub: topic.yaml (themes, keywords, story types, the brief, how Ask talks), sources.yaml (feeds), site.yaml (name, tabs). A mistake stops the build with a message naming the line, so the site never breaks.

Data API

Everything is published as static JSON: api/v1/all.json (everything), brief/latest.json, updates.json, sectors.json, companies.json, catalysts.json, config.json.
